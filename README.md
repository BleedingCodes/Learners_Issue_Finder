# Learners_Issue_Finder
This is part of a project to help with learning how to contribute to a open issues on github projects, also for learning python.

first things first. Start


Before writing any code, write the solution as numbered steps in plain English. One action per line. No syntax, no language, just what needs to happen, in order.

Say what goes in and what comes out. Input, output, and the transformation between them. A lot of "I don't know where to start" is really "I haven't decided what the thing takes and returns yet."

Translate one line at a time. Each English step becomes a few lines of code. If a step needs more than ~5 lines, it isn't small enough — split it.

Trace it by hand with the smallest possible input before you run it. Most logic bugs show up on paper.
